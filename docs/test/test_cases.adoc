=== Akzeptanztest AT-01
Anzeige der geplanten Habits des aktuellen Tages

*Ziel des Tests:*
Überprüfung, ob eine Übersicht aller für den aktuellen Tag geplanten Habits angezeigt wird

*Voraussetzung (Eingabe / Systemzustand):*

- Nutzer ist eingeloggt
- Für den aktuellen Tag sind Habits geplant

*Aktion (Nutzeraktion):*
Nutzer öffnet die Startseite der App

*Erwartetes Ergebnis (Ausgabe):*
Eine Liste aller für den aktuellen Tag geplanten Habits wird angezeigt
